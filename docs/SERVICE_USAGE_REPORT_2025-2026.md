# 서비스 운영 이력 보고서: 2025-2026

## 1. 조사 범위

이 보고서는 번역 서비스에서 확인 가능한 전체 운영 이력을 정리한다. 운영 DB의
추출 기준 시각은 **2026-07-21 21:12:59 KST**(12:12:59 UTC)다. 운영 DB에는
2025-07-14부터 2026-07-04까지의 기록이 있으며, 초기 로컬 자료는 2025년 7월
초까지 거슬러 올라간다.

공개 보고서에는 이메일, Clerk 식별자, IP, API 키, 원문, 번역문, 작업 파일명을
포함하지 않는다.

## 3. 집계 단위

- **HTTP 요청**: 백엔드로 들어온 웹 요청 1건이다. 상태 조회, CORS preflight,
  SSE, 다운로드도 각각 별도 요청으로 집계된다.
- **번역 작업**: 일반적으로 `POST /api/v1/jobs`로 생성되는
  `translation_jobs`의 행 1개다.
- **모델 호출**: AI 모델 사용 이벤트 1건이다. 하나의 번역 작업이 스타일 분석,
  구간 번역, 검증, 후편집, 삽화를 위해 모델을 여러 번 호출할 수 있다.

따라서 HTTP 요청 수나 모델 호출 수를 번역 작업 수로 해석하면 안 된다.

## 5. Railway와 GCP 구간

백엔드와 운영 DB는 2026-06-16에 GCP로 이전했다. Cloud SQL은 Railway
PostgreSQL 데이터를 그대로 이어받았으므로 두 구간 모두의 기준 원본이다.

| 구간 | 남은 작업 | 완료 | 실패 | 기록 범위 |
|---|---:|---:|---:|---|
| Railway 또는 이전 | 1,049 | 776 | 264 | 2025-07-14~2026-06-13 |
| GCP | 4 | 3 | 1 | 2026-06-16~2026-07-04 |

보존 중인 30일 GCP 요청 로그에는 성공한 작업 생성 요청 5건과 작업 삭제 요청
9건이 있다. 따라서 요청 로그의 생성 횟수와 현재 DB에 남은 GCP 작업 수는 일치하지
않는다.

## 6. 모델 및 토큰 사용량

토큰 기록 기능은 2025년 9월에 도입됐다. 2025년 7~9월 모델 호출 850건에는
토큰 수치가 없다. 전체 DB에서 총 토큰이 0인 행은 2,619건이며, 이 중 null은

### 비용 계산 방식

각 호출에 2026-07-21 기준 유료 표준 정가를 적용했다.

- 입력 비용은 `prompt_tokens`를 사용한다.
- 출력 비용은 Gemini 전체 사용량에 포함된 추론 토큰을 반영하기 위해
  `total_tokens - prompt_tokens`를 사용한다.
- Gemini Pro의 기록된 입력이 200,000토큰을 넘으면 해당 호출에 긴 컨텍스트
  단가를 적용한다.
- OpenRouter의 `:free` 모델은 모델 비용 0으로 계산한다.
- 이미지 모델의 기록 토큰은 포함하지만 과거 이미지당 실제 청구액은 완전히
  복원할 수 없다.

이는 **실제 청구액이 아니라 유료 정가 환산액**이다. 무료 티어, 사용자 제공 키,
Vertex 청구, 캐시, 크레딧, 할인, 실패한 provider 호출에 따라 실제 금액은 크게
다를 수 있다. 단가는 2026-07-21에
[Gemini Developer API 가격표](https://ai.google.dev/gemini-api/docs/pricing),
[Vertex AI 가격표](https://cloud.google.com/vertex-ai/generative-ai/pricing),
[OpenRouter 가격표](https://openrouter.ai/pricing)를 확인했다.

추출 자료에 저장하지 않았다.

## 9. 데이터 품질과 한계

- usage log 35,892건은 작업 삭제 시 `ON DELETE SET NULL`이 적용되어
  `job_id`가 없다. 이 행의 토큰은 전체 합계에는 포함된다.
- usage log 926건에는 `user_id`가 없다. 대부분 초기 기록이다.
- 현재 작업 9건에는 usage log가 없다.
- usage log 4,389건에 오류 유형이 기록돼 있다. 이는 모델 이벤트 수이며 고유 실패
  작업 수가 아니다.
- `original_length`, `translated_length`, 처리 시간은 하나의 작업에서 발생한 각
  토큰 이벤트에 반복 저장된다. 단순 합계의 과대계상을 피하기 위해 연결된 작업별
  최댓값을 합산했다.
- Railway CSV의 usage ID 4,018개는 모두 Cloud SQL에도 존재한다. 따라서 해당
  CSV는 검증과 삭제된 작업 ID 식별에만 사용하고 합계에 다시 더하지 않았다.
- Railway 플랫폼의 장기 요청 로그는 남아 있지 않다. 이전된 DB 기록을 GCP 이전
  운영 이력으로 사용했다.
- 2025년 8월·9월 SQLite 파일은 별도 로컬 스냅샷이며 운영 통계에 합산하지 않았다.
